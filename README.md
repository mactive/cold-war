# 铁幕前线 / IRON FRONT

以越南战场指挥桌为视觉场景的冷战卡牌游戏。支持单人人机与双人房间联机。Three.js / WebGL负责地图、环境粒子和射击反馈；联机操作由Cloudflare Worker复算，D1保存权威状态与完整操作日志。

## 启动

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。首次安装依赖需要网络，之后游戏代码、插画、徽章和卡牌数据均从本机提供。桌面浏览器建议1280×720及以上；移动端未适配。

构建及本地预览：

```bash
npm run build
npm run preview
```

## 怎样玩

1. 选择美国／北约或苏联／华约，开始部署；点击起手牌可选择换牌。
2. 点击手牌，再点击我方支援区空位，或右侧「部署到支援区」。点击已有友军可以将新单位插在其前面，调整守护／相邻关系。
3. 单位部署后通常要等下一回合；闪击例外。点击己方单位，再点前线空位推进。按住可攻击的场上单位，拖动弧形箭头到高亮敌军／总部，松手开火；松在空白处或按Esc取消，不花费指挥点。也可先点击单位、再点击目标攻击。
4. 步兵每回合移动或攻击一次；坦克可以先移动再攻击。部署、移动、攻击分别花指挥点。
5. 指令在右侧点击使用，随后按提示选择一个或多个目标；可选多目标需点击「确认执行」。反制付费激活后在敌方回合自动触发。
6. 攻击表现包含发射闪光、弹道拖尾、落点爆炸／烟尘、伤害数字和轻微震动。伤害在弹道抵达时结算，动画期间锁定操作；AI攻击使用同样表现。
7. 总部防御归零即结束。点击「结束回合」或空格交给AI；Esc取消选牌／返回。

顶部「军械库」可浏览80种牌、搜索技能、构筑并保存39张牌库；总部另计。每种稀有度的同名上限为普通4／限定3／特殊2／精英1。保存的新牌组在下一局生效。

设置中可接管当前对局观战、运行100局后台模拟、导出JSON存档或重新选阵营。对局与自建牌组自动保存在当前浏览器的localStorage；刷新后点「继续上次对局」。导出文件用于复盘排错，本版未提供文件导入入口。切换浏览器不会自动共享存档。

## 内容与设定

- 80张卡牌的初始数据来自 `design/coldwar-cards-v0.1.csv`；线上内容以 D1 CMS 发布版本为准。CSV仍用于生成种子和离线备用数据。
- `npm run import` 将CSV导入 `src/game/catalog.js`。`dev`、`build`、`test`、`simulate`启动前自动执行导入。
- 入门牌组与衍生牌从 `design/coldwar-cards-v0.1.json`读取；原始CSV与设计稿保留不变。
- 卡牌技能在 `src/game/engine-core.js`按卡牌ID实现；修改CSV技能文字不会自动生成新的程序效果，修改技能需同时改实现与测试。
- 装备和军事事件截至1990年；心灵技术明确为架空。越南背景是战区美术主题，不把全部装备解释为1968年参战装备。
- 实现了所有80张牌的主动或被动能力、目标选择、临时状态、衍生单位和8种自动反制。
- 玩法以项目v0.1设计稿为准：39张牌库＋总部、共享前线5格、每方后排4格、部署／行动资源共用、最大手牌9张、抽空士气伤害等。没有照搬原作所有扩展系统。

## 实现结构

| 文件 | 作用 |
|---|---|
| `src/game/engine-core.js` | 浏览器与服务端共享的独立规则实例、伤害与反制、目标合法性 |
| `src/game/engine.js` | 本地游戏绑定当前内容配置的规则入口 |
| `src/game/multiplayer.js` | 联机指令校验、视角转换与隐藏信息过滤 |
| `server/multiplayer.js` | 身份、房间、权威结算、日志、积分与重放复核 |
| `src/game/ai.js` | 只依据己方手牌与公开场面评分的启发式AI |
| `src/game/simulation-worker.js` | 后台线程批量模拟，不阻塞界面 |
| `src/ui/scene.js` | Three.js纹理战场、环境粒子与攻击轨迹 |
| `src/main.js` | 操作界面、组牌、存档、选目标、战报 |
| `src/style.css` | 旧纸卡面、金属铭牌、三阵线布局 |
| `tests/engine.test.js` | 规则回归、80张卡代表性执行、确定性复现 |

单位护甲只减免战斗伤害；伤害指令绕过护甲。炮兵、飞机留在后排；轰炸机受战斗机同排制空限制。一次攻击的费用和行动额度在反制之前扣除。反制按激活顺序检查，已经取消的事件不再触发后续同类反制。对手真实剩余费用不显示，面板只显示指挥容量，避免泄露秘密反制。

## 美术

`public/assets/vietnam-table.png`和`public/assets/card-art-atlas.png`使用内置imagegen生成，完整提示词记录在 [public/assets/GENERATION.md](public/assets/GENERATION.md)。西方／东方徽章参考图来自用户附件，以CSS取景复用。图像均保存到项目内。

当前卡牌使用16类共享兵种概念插画，不是80张逐型号考证的独立封面；界面已注明以卡名为准。卡面文字、费用、攻防和交互区域由程序绘制，避免把文字烘焙在图片里。

东方阵营卡背与徽章素材已于2026-10-12替换为用户提供的新版：苏联、越南、东德、古巴；原中国图案替换为越南图案。图片引用带版本参数，避免浏览器沿用旧缓存。

## 当前边界

本版支持本地人机、自由组牌与双人邀请房间。联机使用开房时的CMS标准牌组与卡牌快照，暂不开放自建牌组联机、旁观席或自动匹配。浏览器身份不提供跨设备登录或找回。AI是启发式策略，尚无多步搜索；战役、可视化回放播放器与移动端操作未实现。

## 内容管理后台

地址：https://cold-war.mactive.workers.dev/admin ，管理员账号 `admin`。初始密码单独交付，不写入源码；可在后台「账号安全」中修改。管理员密码修改会撤销全部现有会话。

- 管理80张卡牌、3个衍生单位、2个阵营、2套默认入门牌组和2套AI策略。
- 编辑卡牌名称、费用、攻防、稀有度、历史设定；阵营名称和介绍；入门牌组数量；23项AI行为权重。
- 卡牌ID、兵种和特殊技能文本不可修改：它们与规则代码绑定，新增技能需要同步开发规则引擎。
- 「保存并发布」会校验整个数据集，阻止非法牌组或并发旧版本覆盖；每次修改保存完整历史，支持恢复及JSON导出。
- 游戏通过 `/api/content` 获取最新配置；新对局记录配置快照，继续旧对局时恢复旧配置，避免局中变更。无法联网时使用随代码发布的离线备用数据。
- 预设牌组属于游戏公共配置；玩家浏览器中的自建牌组和个人存档不会自动上传后台。

后端代码在 `server/`，界面在 `admin/`，共享内容结构在 `src/content/`，数据库迁移在 `migrations/`。种子迁移仅初始化一次，后续部署不会覆盖后台编辑。

本机指定的全局 Wrangler 可继续用于发布；项目开发依赖使用较新 Wrangler，以支持当前兼容日期的本地运行时。`.dev.vars` 提供本地 `ADMIN_PASSWORD_HASH`，线上使用同名 Worker Secret（PBKDF2-SHA256 盐化哈希）。密码和初始化材料在忽略版本管理的 `.local/` 中，权限600，不进入静态资源。生产密码只通过后台修改，或执行受控管理员恢复流程。

安全机制：服务端会话校验、HttpOnly/Secure/SameSite Cookie、8小时有效期、同源与CSRF校验、登录限流、参数化SQL和管理页面CSP。无登录状态只能读取供游戏使用的公共静态配置，不能访问管理接口或修改内容。


## 双人房间联机

首页点击「联机房间」，输入昵称建立浏览器身份，然后创建房间并复制链接。朋友打开链接后建立自己的身份并加入。双方阵营由服务端随机分配且互斥，先手也独立随机；双方确认换牌后开始。胜利3分、平局1分、失败0分，积分根据已结束对局在服务器计算。

- 身份凭证（256位随机值）和最近房间编号保存在localStorage。数据库仅存凭证SHA-256摘要；邀请链接只有房间编号。注销会撤销身份、关闭待战房间并将正在进行的对局按认输结算。无法离线注销，以免误以为服务端凭证已撤销。
- 刷新自动恢复最近房间；返回大厅后也能从「我的房间」进入。关闭网页不自动认输。房间24小时无有效操作后，下次访问时关闭且不计积分。
- 联机卡牌与牌组固定为开房时的CMS版本。每个请求使用独立规则实例，避免不同房间版本互相污染。未来修改规则代码时需维护规则版本兼容性。
- 浏览器对伤害、剩余资源与结果积分即时计算并显示预估；隐藏反制和抽牌可能导致预估不同。服务器重新执行指令，拒绝越权、越回合、不合法目标、资源不足或过期版本的请求。客户端提交的状态和积分不会成为权威值。
- D1版本条件更新与日志触发器在同一事务提交。操作唯一编号防止网络重试重复扣费，版本号阻止多窗口覆盖。原始指令、服务端计算值、新增战报、前后状态摘要及拒绝原因可审计。
- 同步使用前台约1秒、后台约4秒的版本轮询；每次操作立即返回权威状态。断网提示后自动重试，重连取最新状态。失败操作不会排队到未来回合执行。
- 两个玩家均以己方在下的视角操作。服务器过滤双方牌库顺序、随机种子、敌方未侦察手牌、反制激活状态与剩余费用；这些数据不会发送到对方浏览器。
- 后台「房间与对战」可查看玩家、阵营、总部、结果、接受／拒绝日志，支持从初始状态重放全部操作并核对状态摘要。日志分页查看，支持已注销身份的历史记录。
