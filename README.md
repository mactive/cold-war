# 铁幕前线 / IRON FRONT

以越南战场指挥桌为视觉场景的冷战卡牌游戏本地试玩版。Three.js / WebGL负责地图场景、环境粒子和射击反馈，HTML/CSS承担可点击卡牌与清晰文字。所有规则与AI在本机运行，无账号、无联网对战、无远程推理服务。

## 启动

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。首次安装依赖需要网络，之后游戏代码、插画、徽章和卡牌数据均从本机提供。桌面浏览器建议1280×720及以上；移动端未适配。

构建及本地预览：

```bash
npm run build
npm run preview
```

## 怎样玩

1. 选择美国／北约或苏联／华约，开始部署；点击起手牌可选择换牌。
2. 点击手牌，再点击我方支援区空位，或右侧「部署到支援区」。点击已有友军可以将新单位插在其前面，调整守护／相邻关系。
3. 单位部署后通常要等下一回合；闪击例外。点击己方单位，再点前线空位推进。按住可攻击的场上单位，拖动弧形箭头到高亮敌军／总部，松手开火；松在空白处或按Esc取消，不花费指挥点。也可先点击单位、再点击目标攻击。
4. 步兵每回合移动或攻击一次；坦克可以先移动再攻击。部署、移动、攻击分别花指挥点。
5. 指令在右侧点击使用，随后按提示选择一个或多个目标；可选多目标需点击「确认执行」。反制付费激活后在敌方回合自动触发。
6. 攻击表现包含发射闪光、弹道拖尾、落点爆炸／烟尘、伤害数字和轻微震动。伤害在弹道抵达时结算，动画期间锁定操作；AI攻击使用同样表现。
7. 总部防御归零即结束。点击「结束回合」或空格交给AI；Esc取消选牌／返回。

顶部「军械库」可浏览80种牌、搜索技能、构筑并保存39张牌库；总部另计。每种稀有度的同名上限为普通4／限定3／特殊2／精英1。保存的新牌组在下一局生效。

设置中可接管当前对局观战、运行100局后台模拟、导出JSON存档或重新选阵营。对局与自建牌组自动保存在当前浏览器的localStorage；刷新后点「继续上次对局」。导出文件用于复盘排错，本版未提供文件导入入口。切换浏览器不会自动共享存档。

## 内容与设定

- 80张卡牌的名称、费用、攻防、稀有度、说明来自 `design/coldwar-cards-v0.1.csv`。
- `npm run import` 将CSV导入 `src/game/catalog.js`。`dev`、`build`、`test`、`simulate`启动前自动执行导入。
- 入门牌组与衍生牌从 `design/coldwar-cards-v0.1.json`读取；原始CSV与设计稿保留不变。
- 卡牌技能在 `src/game/engine.js`按卡牌ID实现；修改CSV技能文字不会自动生成新的程序效果，修改技能需同时改实现与测试。
- 装备和军事事件截至1990年；心灵技术明确为架空。越南背景是战区美术主题，不把全部装备解释为1968年参战装备。
- 实现了所有80张牌的主动或被动能力、目标选择、临时状态、衍生单位和8种自动反制。
- 玩法以项目v0.1设计稿为准：39张牌库＋总部、共享前线5格、每方后排4格、部署／行动资源共用、最大手牌9张、抽空士气伤害等。没有照搬原作所有扩展系统。

## 实现结构

| 文件 | 作用 |
|---|---|
| `src/game/engine.js` | 可序列化的本地规则引擎、伤害与反制、目标合法性 |
| `src/game/ai.js` | 只依据己方手牌与公开场面评分的启发式AI |
| `src/game/simulation-worker.js` | 后台线程批量模拟，不阻塞界面 |
| `src/ui/scene.js` | Three.js纹理战场、环境粒子与攻击轨迹 |
| `src/main.js` | 操作界面、组牌、存档、选目标、战报 |
| `src/style.css` | 旧纸卡面、金属铭牌、三阵线布局 |
| `tests/engine.test.js` | 规则回归、80张卡代表性执行、确定性复现 |

单位护甲只减免战斗伤害；伤害指令绕过护甲。炮兵、飞机留在后排；轰炸机受战斗机同排制空限制。一次攻击的费用和行动额度在反制之前扣除。反制按激活顺序检查，已经取消的事件不再触发后续同类反制。对手真实剩余费用不显示，面板只显示指挥容量，避免泄露秘密反制。

## 验证

```bash
npm test                 # 29项规则回归，含80张卡逐张可执行场景
npm run simulate -- 100  # 100局确定性本地模拟
npm run test:browser     # 需先启动dev；使用本机Google Chrome进行真实点击测试
```

2026-10-12的验收结果保存在 `output/playtest/`：

- 29项规则测试通过；包括攻击与移动限制、守护／制空（含相邻守护互不保护的回归场景）、重甲／烟幕、伏击／冲击、8种反制、回手、控制权、压制、抽空与手牌上限。
- 100局模拟全部终局，没有场地／资源状态异常，没有超时；双方采用相同换牌策略并轮换先手阵营。
- 当前启发式AI结果：北约96胜、华约4胜，平均27.18个交替行动方回合。**这是明显的平衡风险，尚不能用于公平竞技。** 同时受到入门牌组构成与AI决策质量影响，不能当成人类实战胜率。
- 浏览器测试覆盖阵营选择、换牌、部署、移动、坦克攻击总部与敌方前线相邻守护单位、GPS多步骤选目标与ATACMS锁定伤害、反制激活／退款、AI、刷新恢复、组牌保存和后台模拟。未发现JS运行错误或资源加载错误。
- 已检查1600×1000与1280×720布局。截图为真实规则引擎推进后的场面，不是交互占位图。
- 拖拽回归覆盖按住高亮、总部吸附、松手后命中结算、动画操作锁、取消、守护限制、点击兼容、存档恢复和1280×720定位；报告见 `output/playtest/browser-drag-report.json`。

## 美术

`public/assets/vietnam-table.png`和`public/assets/card-art-atlas.png`使用内置imagegen生成，完整提示词记录在 [public/assets/GENERATION.md](public/assets/GENERATION.md)。西方／东方徽章参考图来自用户附件，以CSS取景复用。图像均保存到项目内。

当前卡牌使用16类共享兵种概念插画，不是80张逐型号考证的独立封面；界面已注明以卡名为准。卡面文字、费用、攻防和交互区域由程序绘制，避免把文字烘焙在图片里。

## 当前边界

本版可进行完整本地人机对局与自由组牌；AI是启发式策略，尚无多步搜索，也不保证最优出牌。未实现互联网／局域网联机、用户系统、战役关卡、完整回放播放器与移动端操作。游戏数值保留设计CSV，平衡问题记录在测试结果中。
