## 卡面信息层级
单位牌（17）：
- 左上同一深色徽标：左侧大数字=部署费，右上 K=资源单位，右下小数字=行动费。
- 部署费在打出单位时支付；行动费在每次移动或攻击时支付。
- 下方攻防栏独立显示：攻击 / 兵种图标 / 防御。费用不能与攻防混为一处。
- M48 示例：部署 4、行动 2、攻击 4、防御 5。
- UH-1D 示例：部署 3、行动 1、攻击 2、防御 3。
- T-72A 示例：部署 5、行动 2、攻击 5、防御 5。
- 已部署且可行动的 M48，移动 2 + 攻击 2 = 4 指挥点；这不意味着新部署单位必定能当回合行动。

指令／战术技能牌（18）：
- 左上只有单一部署费与 K，不显示小行动费。
- 不设攻击、防御或兵种战斗数据栏。
- 使用 ! 效果标记、标题和效果文字。
- “战术技能”在本轮作为指令的展示分类，均为一次性效果，未引入独立资源或额外的结算机制。
- 近距空援（3）：对一个地面单位造成 3 点伤害。
- 情报截获（1）：抽一张牌。
- 电子干扰（2）：本回合敌方行动费用 +1。
- 空中补给（2）：抽两张牌。
以上为示意数值和效果，未做平衡性验证。场景图中的小卡数值可能与详图不同；正式组件以确认后的数据为准。

## 两阵营八国卡背（19、20）
本轮暂定跨年代游戏分组，非对全部年代条约成员关系的断言。

| 阵营 | 国家 | 游戏徽章方向 |
|---|---|---|
| 西方 | 美国 | 鹰、星、条纹盾 |
| 西方 | 英国 | 王冠、狮、联合旗盾 |
| 西方 | 法国 | 高卢公鸡、月桂、三色盾 |
| 西方 | 西德 | 联邦鹰、黑红金 |
| 东方 | 苏联 | 红星、镰刀锤、麦穗、地球 |
| 东方 | 越南 | 单颗金星、稻穗、齿轮、红色绶带 |
| 东方 | 东德 | 锤、圆规、麦穗 |
| 东方 | 古巴 | 钥匙、棕榈、海浪、盾 |

西方：蓝灰织纹、旧金描边。东方：暗红框、深橄榄底、旧金徽章。
同一阵营共用框线和纹样，以中央徽章区分国家。
建议每副牌使用统一的所选卡背作为外观，避免单卡来源国通过卡背泄露。
徽章为美术化设计，不作为正式国徽图样使用。
